## Smart Router catalog

Read the deployed service for its current chains, DEX sources, and pool counts. Catalog coverage is separate from the app and protocol deployments.

curl https://api.agentswap.co/api/chains
agentswap chains

The response includes chain_id, name, dexes, and pool_count. Counts are live service observations.

Catalog API reference →

CLI on-chain reads

Intent and policy commands support Base, Arbitrum, BNB Smart Chain, and Robinhood Chain. Configure a chain-specific RPC with AGENTSWAP_RPC_URL_<chainId>.

Default log lookback is 200,000 blocks, except BSC's built-in public RPC uses 9,000. Set a keyed RPC or use --lookback-blocks when you need a different range.
