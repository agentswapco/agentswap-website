Your main wallet owns the Proxy and holds the trading funds until execution. The Proxy pulls only the authorized input and returns proceeds to your main wallet. Your agent wallet holds no trading funds.

Agent instructions

AgentSwap lets owners authorize AI agents through a per-owner User Proxy.
Owners choose allowed actions, input tokens, per-period spending caps,
and expiry. Grants are revocable on-chain. Swap proceeds go to the owner.
Agent wallets only sign with their own key; they do not hold trading funds.
The User Proxy pulls input from the owner's main wallet at execution,
and proceeds return to that main wallet.
With relayed execution, the agent needs no gas balance: the relayer
and solver submit transactions and pay gas. Self-submission pays gas.

App: https://app.agentswap.co
Docs: https://docs.agentswap.co

Multi-aggregator quotes: https://meta-api.agentswap.co
POST /quote (JSON) or POST /quote/stream (SSE).
Use camelCase fields: chainId, tokenIn, tokenOut, amountIn,
taker, slippageBps. API amounts are decimal strings in raw token units.
API guide: https://agentswap.co/docs/api

Smart Router and token catalog: https://api.agentswap.co
GET /api/chains and GET /api/tokens for current coverage.
Smart Router /quote uses snake_case fields and requires an API key.
